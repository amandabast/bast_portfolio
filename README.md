# bast_portfolio
Amanda's personal portfolio page

## Edit and preview

Open `index.html` in a browser for a local preview. All content and styles are in that file.

- **Résumé** — Update the career highlights in the `resume` section and replace `amanda-bast-resume.pdf` when your résumé changes.
- **Selected work** — Edit or duplicate a project’s `<article>` in the `work` section. Add links to public GitHub repositories and Loom recordings where available.

## Publish with GitHub Pages

1. Commit and push the updated files to `main`.
2. On GitHub, open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then click **Save**. GitHub shows the site link on the Pages settings screen once deployment finishes.

Keep `index.html` at the repository root. Use relative paths like `./amanda-bast-resume.pdf` for local files so they work under the repository’s GitHub Pages URL.
